一、为什么必须发布到 HTTPS

要让浏览器允许"添加到主屏幕 / 安装为 App"，页面必须运行在 HTTPS 或 localhost。局域网直连（http://192.168.1.10:8000）只能快速预览，无法触发安装提示。把整个文件夹发布到 Netlify，即可得到一条 https://…netlify.app 链接（免费、自带 HTTPS 证书、自动续期），满足 PWA 安装条件。

重要：发布不需要账号，但不注册认领（Claim）站点会过期失效。拿到链接后务必注册免费账号认领，才能长期保留、更新、管理。

二、用 Netlify 发布（推荐）

把下面整个文件夹上传。已做两处规范校准：manifest 用 .json 后缀（浏览器天然按 application/json 识别，无需额外头）、加入 _headers 让 sw.js 与入口页不缓存。

PWA 家庭物品管理系统/ ├─ index.html 应用入口（主界面 + 快捷路由） ├─ manifest.json 应用清单（名称/图标/主题色/启动） ├─ sw.js Service Worker（离线缓存） ├─ _headers 响应头（sw.js/入口页不缓存，确保改版生效） └─ icons/ ├─ icon-192.png 安装图标 192×192 ├─ icon-512.png 安装图标 512×512 ├─ icon-maskable-512.png 自适应图标（安卓动态图标） └─ apple-touch-icon.png iOS 主屏图标 180×180

发布三步

1
打开拖拽发布页
浏览器访问 app.netlify.com/drop，把上面整个文件夹拖进发布区。
2
得到链接
几秒后得到 https://随机名.netlify.app，即你的正式地址（零配置、立即生效，无需构建）。
3
注册并认领（必须）
注册免费账号，登录后找到刚发布的站点，点 Claim / 认领 归到名下，防止站点过期。

备用方式：Vercel（一键导入）、GitHub Pages（需 GitHub 账号）。任选其一均可。

三、在手机上安装为 App

1
安卓（Chrome / Edge）
用浏览器打开部署链接，首次加载后底部或菜单会提示「添加至主屏幕 / 安装应用」；也可点菜单 ⋮ → 添加至主屏幕。
2
iPhone（Safari）
点分享按钮 ↑ → 向下找「添加到主屏幕」→ 点「添加」。iOS 会用 apple-touch-icon 生成图标。
3
启动
点主屏图标即可全屏运行，无地址栏。首次联网加载后，离线也能打开已缓存界面。
提醒：未认领的 Drop 站点带临时密码保护，手机上无法正确验证 PWA 安装/离线。所以①务必先认领，再②在手机测安装。

四、⚠️ 关键：为什么改了没效果 / 删不掉

真正原因：浏览器对 Service Worker 的更新检查周期约 24 小时，且旧版本的 SW 会把页面缓存成旧 JS。之前"删不掉王奶奶"正是因为你手机执行的是第一次缓存下来的旧逻辑，我改的代码在磁盘上没被加载。本次已把缓存版本升到 v2、SW 改为优先拉新代码、并用 _headers 让 sw.js 与 index.html 不缓存。
  • 发布后第一次在手机上彻底打开，然后关闭应用重开一次，确保拉到最新。
  • 若仍显示旧内容，浏览器里强制刷新（安卓 Chrome 可先清站点数据再重开）。

六、以后如何更新

不要回到 app.netlify.com/drop 重新拖拽（那会新建一个站点、换新域名）。正确做法：

  1. 登录 Netlify，进入你已认领的这个站点
  2. 打开 Deploys 页面
  3. 把更新后的整个文件夹拖进该页的拖拽区，在同一站点生成新部署

这样会覆盖当前站点，链接不变，手机重开应用即拿到新版。
